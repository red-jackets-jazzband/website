## Responsable
Le Red Jackets Jazzband est responsable des données décrites sur cette page. Questions, demandes de suppression ou réclamations : [info@redjackets.nl](mailto:info@redjackets.nl). Nous répondons dans un délai d'un mois.

## Visiter ce site
Les pages, morceaux et setlists sont de simples fichiers. Aucune connexion n'est demandée et nous ne déposons pas de cookies de suivi. Vos setlists, versions de morceaux et réglages restent dans votre navigateur (stockage local) et ne quittent pas votre appareil, sauf si vous activez **Connecter les appareils** ci-dessous.

Certaines pages intègrent des vidéos ou de la musique de YouTube, Spotify ou SoundCloud. Lire l'un de ces contenus envoie votre requête à ce service, selon sa propre politique de confidentialité.

## Connecter les appareils (facultatif)
Connecter les appareils garde vos setlists personnelles et vos propres versions de morceaux identiques sur votre téléphone, votre tablette et votre ordinateur. La fonction est désactivée tant que vous n'appuyez pas sur **Connecter cet appareil**. Les **espaces partagés** (l'onglet Partagé) sont un choix distinct qui fonctionne de la même façon : vous en créez un ou en rejoignez un sous le nom de votre choix, et les versions de morceaux et setlists que vous y mettez sont visibles, sous ce nom, de toute personne qui a le code de l'espace. Tant que vous ne faites ni l'un ni l'autre, le site n'envoie rien au serveur de synchronisation.

- **Ce qui est stocké.** Vos données sont chiffrées dans votre navigateur avec une clé issue de votre code de synchronisation. Le serveur ne conserve que les données chiffrées, un numéro de version et un identifiant dérivé du code. Nous ne pouvons pas lire vos setlists, et le code n'atteint jamais le serveur.
- **Où.** Sur un serveur de Cloudflare, Inc., qui traite les données pour notre compte.
- **Adresses IP.** Pour limiter les abus, le serveur compte combien de copies de synchronisation sont créées depuis une même adresse. Il ne conserve pour cela qu'un hachage de votre adresse IP, mélangé à un sel qui change chaque jour, et le supprime après un jour. Cloudflare peut aussi voir votre adresse IP lors du traitement de la requête, comme tout hébergeur web.
- **Cookies et comptes.** Aucun. Toute personne qui a votre code de synchronisation peut lire et modifier vos données synchronisées : gardez-le privé.
- **Durée.** Une copie de synchronisation non mise à jour depuis 18 mois est supprimée automatiquement.
- **Suppression.** Appuyez sur **Supprimer la copie du serveur** dans la boîte de dialogue (pour un espace partagé, dans son onglet Partagé). Vos données sur vos appareils restent ; **Déconnecter** arrête la synchronisation sur un appareil.

Vos préférences (instrument, tempo, panneaux) ne sont pas synchronisées.

## Vos droits
Vous pouvez demander l'accès à vos données, leur rectification ou leur suppression, et déposer une réclamation auprès de l'autorité néerlandaise de protection des données (Autoriteit Persoonsgegevens). Les données synchronisées étant chiffrées et le code ne nous parvient jamais, nous ne pouvons ni trouver ni lire votre copie. Ne nous envoyez pas votre code de synchronisation : quiconque le lit accède à vos données. Utilisez **Supprimer la copie du serveur**, ou laissez la copie expirer au bout de 18 mois.
